# 📸 instagram-clone-react-django

A full-stack Instagram clone using React and Django.

## 🛠️ Tech Stack
- ⚛️ React (Frontend)
- 🐍 Django REST Framework (Backend)
- 🐘 PostgreSQL

## ✨ Features
- Dynamic Instagram feed
- Props and State management
- REST API integration

## 📚 What I Learned
- 💡 How to connect React with Django
- 🔄 Props & State for dynamic feed
- 🔗 Use of REST API 
- 🗂️ Frontend & Backend folder structure
- 🛠️ Full-stack project setup
